# CrossHostCoV
Core code and supplementary data for the manuscript _"Proactive AI-Experimental Framework Identifies Coronaviruses with Human Infectivity Potential_"

# CoreCode
The py code is for model training and prediction.
The .7z file is for the result of RNAEenie.

For the input file (CrossHost_preMatrix_ORF.csv), please see the 01_CrossHost_preMatrix_ORF.7z in CrossHostCoV/SupplementaryData.

# SupplementaryData
Related data in this research including dataset, risk result, strain information, etc.

# Requirements
sklearn v0.24.2

pandas v1.1.5

numpy v1.19.5

torch v1.8.1

For RNAErnie (manuscript at https://www.nature.com/articles/s42256-024-00836-4; src available at https://github.com/CatIIIIIIII/RNAErnie), its data processing output is required but you do not need to install it within the same environment.
